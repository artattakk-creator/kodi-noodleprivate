# XCMate · Space Premium

Verbindlich ausgewähltes **Design 1 – Space Premium**. Freigegebene erste vier Grafikentwürfe werden unter diesem Pfad archiviert, nicht als direkt produktives Add-on-Paket: `artwork/xcmate/space-premium/`.

Die vier Zieldateien heißen `icon-512.png`, `wordmark-white.png`, `splash-1920.jpg`, `fanart-1920.jpg`. Binäre Uploads werden erst dann als vorhanden deklariert, wenn sie über GitHub-API und SHA-256 geprüft wurden.

**Abnahme-Workflow ab jetzt:** Entwurf erstellen → Nutzer gibt konkrete Grafiken frei → Binärdateien in passendes Themeverzeichnis hochladen → vollständige Prüfsummen-/Auflösungsprüfung → erst später nach separater Integrationsfreigabe ins Kodi-Add-on übernehmen. Die Live-TV-Oberfläche 0.1.26 ist auf Funktions-FREEZE. Weitere Designs kommen in eigene Verzeichnisse; Varianten 2/3 sind nicht produktiv.
