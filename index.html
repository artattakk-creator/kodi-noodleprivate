Noodle Private – Kodi-Repository

Einmalige Installation

repository.noodleprivate-0.1.0.zip herunterladen

Nur diese Repository-ZIP über Kodi → Add-ons → Aus ZIP-Datei installieren öffnen. Nicht direkt als Video abspielen.

Danach in Kodi

  1. Add-ons → Aus Repository installieren.
  2. Noodle Private Repository → Video-Add-ons → Noodle Private → Installieren.
  3. Updates kommen anschließend über Kodi automatisch aus diesem Repository.

Für Kodi als HTTPS-Dateiquelle kann diese Seitenadresse benutzt werden: https://artattakk-creator.github.io/kodi-noodleprivate/

Die GitHub-RAW-Datei und das eigentliche Video-Plugin-ZIP sind keine alternativen Repository-Installer. Favoriten und Verlauf liegen lokal in Kodi.
