GS Media Kodi Repository

Ein Repository für alle eigenen Kodi-Add-ons von GS Media mit zentralen Updates.

GS Media Repository für Kodi installieren (ZIP)

Nur diese ZIP über Kodi → Add-ons → Aus ZIP-Datei installieren auswählen. Die RAW-Datei nicht als Video öffnen.

  1. Repository-ZIP installieren
  2. Aus Repository installieren → GS Media Kodi Repository
  3. Video-Add-ons → Noodle Private
