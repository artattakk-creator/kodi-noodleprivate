# XCMate – Space Premium 1.0.0

Offiziell freigegebenes GS Media Artwork mit 98 unveränderten PNG/JPEG-Assets, validiert gegen `MASTER_TRACKER_98.json` vom 20.10.2026. Der Tracker und die Provenienz bleiben Bestandteil des separaten Quelldatenpakets, nicht dieses installierbaren Themes.

**Installation:** XCMate Core >= 0.1.30 und < 0.2.0 → Einstellungen → Darstellung & Sprache → XCMate-Designs → ZIP-Datei installieren. Dieses ZIP ist **kein Kodi Add-on** und darf nicht über den globalen Kodi Add-on Installer installiert werden.

Das Theme enthält ausschließlich ein deklaratives Manifest und Bilddaten. Kodi Titan BINGIE MOD, globale Keymaps, Player-Steuerung und andere Add-ons bleiben unverändert. Die tatsächliche Darstellung sämtlicher 98 Bildpositionen muss zusätzlich in XCMate Core angebunden werden; dieses Paket alleine erweitert keine Kodi-XML-Layouts.

Die Palette entspricht den in PR #50 dokumentierten Space-Premium-Farbtokens.

Compatibility port: XCMate 0.1.29.24; current GuideGrid/Media/Live/OSD texture-only hooks. The original 98 image byte hashes are unchanged. Device acceptance pending.
