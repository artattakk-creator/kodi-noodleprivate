XCMate private SMB2 dependencies

pysmb 1.2.14 (zlib/libpng), pyasn1 0.6.1 (BSD-2-Clause), pinned PyPI source.
Pure Python, no binary module, no runtime pip/dependency download.

Alterations: private import namespace; quiet packet/auth logging; unused terminal
progress disabled; NTLM nonce/session randomness uses os.urandom. The XCMate
adapter restricts negotiation to SMB2, verifies inbound signing, forces exclusive
new file creation and server-side no-replace rename. SMB1, guest/unsigned and
SMB3-encryption-required endpoints are refused; never silently downgraded.
