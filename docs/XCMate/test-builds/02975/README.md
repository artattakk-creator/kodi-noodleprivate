Nach bestätigter Pilot-Veröffentlichung in Kodi: Add-ons → Benutzer-Add-ons → Add-on-Repositories → vorhandenes GS Media Pilot → Auf Aktualisierungen prüfen; danach XCMate → Informationen → Aktualisieren → **0.1.29.75 aus GS Media Pilot** auswählen. Kein GS-Media-Setup erneut ausführen, kein Profil zurücksetzen. Alternativ das ZIP als Update über die vorhandene Installation installieren.

Die neue native Hero-Anpassung benötigt weiterhin den bestehenden Vorschau-/Sicherungs-/Zustimmungsdialog in der technischen BINGIE-Integration. Sie wird beim Update nicht ungefragt in fremde Skin-Dateien geschrieben. Bei unbekannter Skin-Version die Schutzsperre respektieren und den Diagnosecode melden.

Erst einmal Live-TV-Zurück prüfen. Bei Hänger keine 20 Wiederholungen erzwingen. Der native RK3528-Stop ohne ACK bleibt ein offener Gerätebefund.
