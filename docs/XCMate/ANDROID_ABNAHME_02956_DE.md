## Fehler unterscheiden

`CACHE_UNWRITABLE` / `CACHE_STORAGE_FULL` / `LOCKED` gefolgt von `READ_ONLY` und positiven Itemzahlen: Snapshot kann nicht publiziert werden, der lokale Katalog darf trotzdem sichtbar sein. Keines dieser Wörter belegt allein vollen Gerätespeicher. SQLite kann separat nicht lesbar sein. `BUDGET`, `INDEX_MISSING`, `DISABLED`, fehlende/falsche Portal-ID und `BLOCKED_NO_RELOAD_HOOK` separat berichten. Keine globale Retry-/Import-/Löschaktion als Testhilfe.

Gemeinsame Bilder: `TMDB_DISABLED`, `TMDB_TOKEN_MISSING`, `NOT_CLASSIFIED_MOVIE`, `NO_YEAR`, `NO_MATCH`, `NO_VALID_URL` und vorhandene HTTP-/DNS-/Hostfehler erklären einen offenen Bildfall; sie ersetzen den echten visuellen Bildnachweis nicht. TV Spielfilm ohne autorisierte API bleibt ausdrücklich BLOCKED.

Rückmeldung genügt als `Gate | Status | Beobachtung/Uhrzeit`. Bei FAIL keine weiteren belastenden Zyklen erzwingen. Keine Rohlogs öffentlich posten. Merge und Veröffentlichung erst nach ausdrücklicher Nutzerfreigabe.
